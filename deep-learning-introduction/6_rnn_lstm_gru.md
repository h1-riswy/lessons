# 第6章：RNN・LSTM・GRU - 系列データを扱う

前章の CNN は「画像のどこにあっても同じ猫は猫」という **位置不変性** を活かすアーキテクチャでした。しかし世の中には、順番そのものに意味があるデータがあります。

> 「犬が人を噛んだ」と「人が犬を噛んだ」— 単語の集合は同じでも、意味は正反対

本章では、こうした **系列データ（sequential data）** を扱う RNN と、その改良版である LSTM・GRU を見ていきます。現在の主流は第7章で扱う Transformer ですが、その必要性を理解するには、RNN が何に苦しんだのかを知る必要があります。

## 6.1 系列データと再帰構造

### 時系列・自然言語の何が特殊なのか

系列データには、これまでのデータと違う 3 つの特徴があります。

| 特徴 | 説明 | 例 |
|------|------|-----|
| **順序に意味がある** | 並び替えると意味が変わる | 単語の並び、株価の推移 |
| **長さが可変** | 入力ごとに要素数が違う | 3 単語の文も 100 単語の文もある |
| **文脈依存** | 前の要素が後の解釈を左右する | 「それ」が何を指すかは前文次第 |

全結合層や CNN は「固定長の入力」を前提としています。文章ごとに長さが違うデータをそのまま入れることはできません。

### RNN の基本構造と隠れ状態

**RNN（Recurrent Neural Network、再帰型ニューラルネットワーク）** は、**隠れ状態（hidden state）** という「これまでの記憶」を持ち回ることでこれを解決します。

![RNNの構造](../ai-introduction/rnn-architecture.svg)

```
       ┌──────────┐
  x_t →│   RNN    │→ y_t          h: 隠れ状態（記憶）
       │  セル     │
       └──┬───▲───┘
          │   │
        h_t   h_(t-1)
          └───┘  ← 出力した記憶を次の入力として自分に戻す（再帰）
```

1 ステップの計算はシンプルです。

```
h_t = tanh(W_x · x_t  +  W_h · h_(t-1)  +  b)
             ↑新しい入力    ↑前の記憶

y_t = W_y · h_t + b_y
```

ポイントは、`W_x`, `W_h`, `W_y` が **全ステップで共通** であることです。CNN のフィルタ共有と同じ発想で、これにより任意の長さの系列を同じパラメータで処理できます。

### 時間方向への展開

再帰構造は、時間方向に引き伸ばす（unroll する）と普通のネットワークとして見えます。

```
"I"      "love"    "deep"    "learning"
  ↓         ↓         ↓          ↓
 x_1       x_2       x_3        x_4
  ↓         ↓         ↓          ↓
[RNN] h1→ [RNN] h2→ [RNN] h3→ [RNN] → h4
  ↓         ↓         ↓          ↓
 y_1       y_2       y_3        y_4
  └─ 同じ重みを使い回している ─┘
```

展開してしまえば、学習は第3章の誤差逆伝播法と同じです。ただし時間方向にさかのぼって勾配を伝えるため、特に **BPTT（Backpropagation Through Time、通時的誤差逆伝播）** と呼ばれます。

RNN は入出力の対応づけ方でいくつかのパターンに分かれます。

```
many-to-one     one-to-many      many-to-many
 x x x x         x                x x x x
 ↓ ↓ ↓ ↓         ↓                ↓ ↓ ↓ ↓
 ■─■─■─■         ■─■─■─■          ■─■─■─■
       ↓         ↓ ↓ ↓ ↓          ↓ ↓ ↓ ↓
       y         y y y y          y y y y
 感情分析        画像→キャプション  品詞タグ付け
```

## 6.2 RNN の課題

### 勾配消失・勾配爆発

RNN は理論上いくらでも長い系列を扱えますが、実際には長い系列でうまく学習できません。

![勾配消失と勾配爆発](../ai-introduction/rnn-vanishing-exploding-gradients.svg)

BPTT では、時刻 t の誤差を時刻 1 まで伝えるのに、同じ重み行列を**何度も掛け算する**ことになります。

```
50 ステップさかのぼると、およそ W を 50 回掛けることになる

W の影響が 0.9 倍相当なら:  0.9^50 ≒ 0.005   → 勾配消失（学習が進まない）
W の影響が 1.1 倍相当なら:  1.1^50 ≒ 117     → 勾配爆発（値が発散する）
```

- **勾配消失（vanishing gradient）**：遠い過去に向かう勾配がほぼ 0 になり、そこのパラメータが更新されない
- **勾配爆発（exploding gradient）**：勾配が発散し、損失が NaN になる

勾配爆発は、**勾配クリッピング**（勾配のノルムに上限を設ける）で比較的簡単に対処できます。

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

厄介なのは勾配消失のほうです。値が静かに 0 に近づくだけなので、エラーも出ず、ただ「精度が上がらない」という形で現れます。

### 長期依存関係の学習が難しい理由

勾配消失の実害は、**長期依存関係（long-term dependency）** が学べないことです。

```
「私はフランスで生まれ育ち、そこでの生活は……（中略・50単語）……
  だから私は流暢な ____ を話す」
                      ↑ 正解は「フランス語」

50 単語前の "フランス" を覚えておく必要があるが、
素の RNN では勾配がそこまで届かず、直前の数単語しか参照できない
```

実用上、素の RNN が記憶できるのは**せいぜい 10 ステップ程度**と言われます。これでは文章も時系列も扱えません。

## 6.3 LSTM と GRU

### ゲート機構という発想

この問題を解決したのが **LSTM（Long Short-Term Memory）** です。1997 年に提案され、2010 年代の自然言語処理を支えました。

アイデアは 2 つです。

1. **セル状態（cell state）** という、情報が素通りできる「ベルトコンベア」を用意する
2. **ゲート** で、そこに何を書き込み、何を捨て、何を読み出すかを学習で制御する

```
セル状態 C: ────────────────────────→  掛け算と足し算だけで通過できる
                ↑      ↑      ↓        （勾配が減衰しにくい経路）
              忘却    入力   出力
              ゲート  ゲート  ゲート
```

CNN の残差接続（第5章）と同じく「勾配が素通りできる経路を作る」という発想です。

### 忘却ゲート・入力ゲート・出力ゲート

![LSTMの構造](../ai-introduction/lstm-architecture.svg)

各ゲートは、Sigmoid 関数で 0〜1 の値を出す小さなニューラルネットワークです。この値を掛けることで「どれだけ通すか」を調節します。

| ゲート | 役割 | 直感的な意味 |
|--------|------|--------------|
| **忘却ゲート** (forget) | セル状態の古い情報をどれだけ残すか | 「主語が変わったので前の主語は忘れる」 |
| **入力ゲート** (input) | 新しい情報をどれだけ書き込むか | 「新しい主語を記憶する」 |
| **出力ゲート** (output) | セル状態のどこを今の出力に使うか | 「今は主語の単複だけ使いたい」 |

```
0 に近いゲート値 → 情報を遮断
1 に近いゲート値 → 情報をそのまま通す
             ↑ この開き具合を、データから学習する
```

![LSTMとRNNの比較](../ai-introduction/lstm-vs-rnn.svg)

PyTorch では 1 行で使えます。入出力の**形状**を押さえるのが実務上の要点です。

```python
import torch
import torch.nn as nn

lstm = nn.LSTM(input_size=64, hidden_size=128, num_layers=2, batch_first=True)

# batch_first=True のとき入力は (バッチ, 系列長, 特徴次元)
x = torch.randn(32, 20, 64)          # 32文, 各20トークン, 各トークン64次元

out, (h_n, c_n) = lstm(x)

print(out.shape)    # torch.Size([32, 20, 128])  全ステップの隠れ状態
print(h_n.shape)    # torch.Size([2, 32, 128])   最終ステップの隠れ状態(層ごと)
print(c_n.shape)    # torch.Size([2, 32, 128])   最終ステップのセル状態
```

**よくある誤解**：`batch_first=False`（PyTorch のデフォルト）だと入力は `(系列長, バッチ, 特徴次元)` になります。形状のバグの大半はここです。明示的に `batch_first=True` を指定するのが安全です。

用途による使い分け：

- 文全体を 1 つのベクトルにしたい（感情分析など）→ `h_n` の最終層を使う
- 各トークンに出力が要る（品詞タグ付けなど）→ `out` を使う

```python
# many-to-one: 文の感情を2クラス分類
class SentimentModel(nn.Module):
    def __init__(self, vocab_size, emb=64, hid=128):
        super().__init__()
        self.emb = nn.Embedding(vocab_size, emb)
        self.lstm = nn.LSTM(emb, hid, batch_first=True)
        self.fc = nn.Linear(hid, 2)

    def forward(self, ids):              # ids: (batch, seq_len)
        out, (h_n, _) = self.lstm(self.emb(ids))
        return self.fc(h_n[-1])          # 最終層の最終隠れ状態 -> (batch, 2)
```

### GRU による簡略化

**GRU（Gated Recurrent Unit）** は 2014 年に提案された、LSTM の簡略版です。

![GRUの構造](../ai-introduction/gru-architecture.svg)

```
LSTM                          GRU
 ゲート 3 つ                   ゲート 2 つ（リセット / 更新）
 セル状態 C と 隠れ状態 h       隠れ状態 h のみ
 パラメータ多い                パラメータ約 3/4、学習が速い
```

- **リセットゲート**：過去の情報をどれだけ無視するか
- **更新ゲート**：LSTM の忘却ゲートと入力ゲートを 1 つにまとめたもの

精度はタスクによりけりで、**どちらが優れているとは一概に言えません**。データが少ない、あるいは速度を優先したいなら GRU、というのが一般的な使い分けです。

```python
gru = nn.GRU(input_size=64, hidden_size=128, batch_first=True)
out, h_n = gru(x)       # 戻り値が 2 つ（セル状態がない点が LSTM との違い）
```

### 双方向 RNN

素の RNN は「過去から未来」の一方向にしか進みません。しかし文章の理解では、後ろの文脈も役に立ちます。

```
「彼は銀行に行った」    → 金融機関
「彼は川の銀行に座った」 → 土手（bank）
        ↑ この語の意味は、後ろまで読まないと確定しない
```

**双方向 RNN（Bidirectional RNN）** は、順方向と逆方向の 2 つの RNN を走らせ、各時刻の隠れ状態を連結します。

![双方向RNNの構造](../ai-introduction/bidirectional-rnn-architecture.svg)

```
順方向: →→→→→→→→
逆方向: ←←←←←←←←
        各時刻で両者を結合 → 出力次元が 2 倍になる
```

```python
bilstm = nn.LSTM(64, 128, batch_first=True, bidirectional=True)
out, (h_n, c_n) = bilstm(torch.randn(32, 20, 64))
print(out.shape)    # torch.Size([32, 20, 256])  ← 128 * 2（順+逆）
```

**制約**：双方向にするには系列全体が事前に揃っている必要があります。リアルタイム音声認識のように、未来の入力がまだ存在しないタスクには使えません。

## 6.4 応用と限界

### Seq2Seq と Encoder-Decoder

機械翻訳では、入力と出力の長さが一致しません（日本語 8 単語 → 英語 12 単語）。これを扱うのが **Seq2Seq（Sequence-to-Sequence）**、別名 **Encoder-Decoder** 構造です。

```
      Encoder（入力を理解する）              Decoder（出力を生成する）
 私  は  猫  が  好き                       I  like  cats  <eos>
  ↓   ↓   ↓   ↓   ↓                        ↑    ↑     ↑     ↑
 ■──■──■──■──■  ══> [文脈ベクトル] ══>  ■──■────■─────■
                        （固定長）           ↑
                                        <sos> から順に1語ずつ生成
```

Encoder が入力文全体を 1 本の固定長ベクトル（文脈ベクトル）に圧縮し、Decoder がそこから出力を 1 語ずつ生成します。

```python
# 概念コード（Encoder の最終状態を Decoder の初期状態として渡す）
_, (h, c) = encoder_lstm(src_emb)          # 入力文を読み切る
out, _ = decoder_lstm(tgt_emb, (h, c))     # その記憶から出力を生成
logits = fc(out)                            # 各ステップで語彙上の確率分布
```

主な応用先：

| 分野 | タスク |
|------|--------|
| 自然言語処理 | 機械翻訳、要約、対話応答、固有表現抽出 |
| 音声 | 音声認識、音声合成 |
| 時系列 | 需要予測、株価予測、異常検知、センサーデータ解析 |

### RNN 系の 2 つの壁

RNN 系アーキテクチャは大きな成果を上げましたが、2 つの構造的な限界を抱えていました。

**壁1：固定長ボトルネック**

Seq2Seq では、入力文がどれだけ長くても、1 本の固定長ベクトルに押し込められます。

```
短い文:  「猫が好き」        → [512次元] ○ 十分
長い文:  「……（50単語）……」 → [512次元] × 情報が入りきらない
```

実際、入力文が長くなるほど翻訳精度が落ちることが知られていました。

**壁2：逐次処理ゆえの並列化の壁**

こちらがより深刻です。RNN は `h_t` を計算するのに `h_(t-1)` が必要なため、**原理的に時間方向の並列計算ができません**。

```
RNN:   x1 → x2 → x3 → ... → x100     100 ステップを順番に待つ
       （GPU が何千コアあっても、1つずつしか進めない）

CNN:   [x1 x2 x3 ... x100]            全部同時に計算できる
```

GPU の性能は「大量の計算を同時に行う」ことで発揮されます。RNN はその強みを活かせないため、モデルを大きくしても、データを増やしても、学習時間が線形に伸びてしまいます。

> **実務での位置づけ**：この「並列化できない」という制約こそが、2017 年の Transformer 登場の直接的な動機でした。Transformer は再帰構造を捨て、系列の全要素を一度に処理することで、GPU をフルに使った大規模学習を可能にしました。現在の LLM が存在するのはこのためです。**その仕組みは第7章で扱います。**

なお RNN 系が完全に不要になったわけではありません。小規模な時系列予測や、計算資源が限られる組込み環境では、軽量な LSTM / GRU が今も現役です。

## まとめ

本章では、系列データを扱う RNN 系のアーキテクチャを学びました：

✅ **RNN は隠れ状態を持ち回ることで、可変長の系列と文脈を扱える**
✅ **同じ重みを繰り返し掛けるため、勾配消失・勾配爆発が起き、長期依存が学べない**
✅ **LSTM はセル状態とゲート機構で情報の取捨選択を学習し、長期記憶を実現した**
✅ **GRU は LSTM の簡略版。双方向 RNN は前後の文脈を同時に使う**
✅ **Seq2Seq の固定長ボトルネックと、逐次処理による並列化の壁が RNN の限界**

次章では、この限界を突破し、現代の生成 AI の基盤となった Attention と Transformer を扱います。
